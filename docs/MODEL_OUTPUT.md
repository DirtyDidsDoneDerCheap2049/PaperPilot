# 模型输出与报告

模型输出分为结构化分析和读者正文。前者用于程序校验、证据索引及调度，后者用于回答研究问题。内部 JSON、提示词和思考过程不进入最终报告。

## 结构化结果

论文画像、问题证据、规划行动和审计结果需要符合对应字段约束。程序检查对象类型、必填字段、论文 ID、枚举和引用；格式修正不能凭空补事实。

引文必须能定位到解析文本，来源哈希和字符范围随证据保存。仅有摘要的结论标明范围，无法绑定原文的内容不能充当直接全文证据。检查细节见[主张与证据](DOMAIN_PROFILES.md)。

单次输出达到长度上限可能截断 JSON；长思考也占输出预算。调整输出预算、拆分输入或重试应保留实际失败原因，不能把截断输出保存成成功画像。

## 报告结构

| 类型 | 优先呈现 |
| --- | --- |
| 研究空白 | 具体空白点、与最近工作的差异、依据及验证思路 |
| 数值比较 | 已核实答案、模型与数值表、比较条件及范围 |
| 综述 | 主题结论、方法路线、共同问题与证据 |
| 事实核查 | 直接判断、支持或不支持的原文、无法确认的部分 |

报告使用自然段、短标题和必要的表格。空白标题直接点出差异，不以“研究判断”“仍待研究”等泛泛标题代替。数字、论文归属和引用编号不能为改善表达而改变。

不确定性对应具体原因：原文未获得、字段缺失、候选差异未核实或实验收益未知。这些情况分别说明，不给所有候选反复加同一种“待核实”。作者未报告与本次未读到也应区分。

## Naturawrite

运行时写作规则位于 [Naturawrite SKILL](../src/knowledge/policies/naturawrite/SKILL.md)，由 [writing_policy.py](../src/llm/writing_policy.py) 加载，用于新报告和修订。

规则要求先回答问题，去掉自言自语、空转修辞和重复免责声明，保留证据、不确定性及必要术语。自然写作不等于放宽事实要求，也不把润色当成核实。逐篇 JSON 抽取不重复附带整套写作规则。

## 检查与部分交付

初稿接受内容检查，核对直接回答、引用、证据范围及夸大表述，允许一次修订。仍未通过时，程序基于已核实资料生成部分报告，说明未完成项；初稿、检查对象及诊断保存在研究快照。

部分报告不是被拒绝初稿的直接放行，也不把审核意见当正文。鉴权、余额、取消和外部请求错误按真实任务状态处理。模型复核可能遗漏语义错误，关键结论仍需人工查看原文。

## 自动修订报告

请求改写、压缩、调整格式或结构时，Agent 可以选择报告修订；要求新证据或重查事实时，仍使用研究流程，不需要额外按钮。

修订读取已有报告和保存的分析、候选及引用，不重新搜索、下载或阅读 PDF。默认最多四次修订相关请求；含糊意图可能增加一次分类请求。来源在任务首次执行时固定，成功结果不会因重试重复生成。

原报告保留，新版单独保存。程序检查引用编号、内部字段及前后事实一致性，失败不覆盖原稿。缺少支撑资料时只能说明限制，不能利用改写补造结论。

报告的中文显示名称与文件路径分开保存；命名不改变报告正文或验证状态。

## 讨论与流式显示

直接讨论基于现有会话和有限论文摘录回答，不新增检索。讨论消息默认展开；带有报告来源路径也不会因此变成折叠报告卡片。研究报告则可打开其对应版本。

实时过程呈现在对话中：正文逐段更新，思考保持单行预览，不展开长链路，也不显示原始 JSON。阅读摘要和草稿尚需后续校验，最终结论以交付报告及证据为准。

## 兼容模型服务

设置支持 OpenAI Chat Completions 兼容端点，模型 ID 可手填。输出长度可使用 `max_tokens`、`max_completion_tokens` 或不发送长度参数；JSON 模式及允许的附加参数可配置。

自动模式只向 DeepSeek 官方端点发送专用思考参数。官方预设为 `deepseek-flash`、`max`、65,536 token 输出预算、600 秒超时；这些是程序配置，不是对供应商当前模型能力或价格的承诺。可用 ID 以服务返回为准。

兼容端点需要支持实际使用的流式参数。Responses、Anthropic 原生协议和所有厂商的逐项兼容尚未实现或验证。

## 输入与用量

[context_budget.py](../src/llm/context_budget.py)使用设置中的上下文容量；未配置时，官方 DeepSeek 按 1,048,576、其他兼容端点按 128,000 估算，另预留输出及指令空间。保守字节估算不等于服务商 token 计数。

全文放得下时直接输入，超预算时选取相关完整章节和表格，并记录部分读取。长上下文不保证证据利用率，向量相关性也不证明结论。费用与缓存统计见[模型用量](MODEL_COST.md)。
