# 论文库整理

「自动整理」为已有论文生成主分类、方法标签和阅读摘要，并折叠能确认的重复记录。它不检索新论文，不判断研究新颖性，也不删除原 PDF、解析或历史引用。

## 分类与筛选

主分类描述论文的主要研究任务。不同模态、非传统输入和特殊应用场景可以保留为有用类别，不强制归入同一个传统任务。

方法标签描述具体技术。以下四个维度独立筛选，无明确依据时留空：

| 维度 | 可用值与判定 |
| --- | --- |
| 输入时序 | 单帧、多帧 / 时序；多视图和迭代次数不等于多帧 |
| 先验 | 单目深度、基础模型、几何、外部传感器先验；任务本身不自动算使用先验 |
| 训练方式 | 有监督、自监督、无监督、半监督，以已有资料为准 |
| 方法机制 | 知识蒸馏、先验融合、跨任务迁移；冻结编码器或使用预训练权重不自动算蒸馏 |

一篇论文可有多个独立维度，主分类只选一个。摘要用一两句说明研究问题和主要方法，不写思考过程，也不为分类补造实验结果。

## 固定目录与增量整理

固定分类目录保存为工作区 `notes/library-taxonomy.json`。已有目录时，模型从中选择，不重新命名或新建另一套；信息不足进入“待分类”。

没有目录时，模型根据抽样资料生成通常 4–12、最多 16 个主题，“待分类”由程序补充。目录不按年份、下载状态或输出字段组织，主题细节留给标签。

整理前显示待处理数量和调用估算。按标题、摘要、解析片段及规则等输入指纹复用未变结果，只处理新增或变化项。目录或规则变化可能使已有结果失效，应重新检查待处理量。

整理作用于整个可见工作区，不限于当前筛选页；隐藏项和先验笔记排除。每批最多 12 篇，支持最多 1,500 篇、60 分钟和 600 次请求，失败重试计入预算。

## 规则与保存

模型规则位于 [library-organizer](../src/knowledge/policies/library-organizer/SKILL.md)，分类目录与逐篇分类分别调用。代码检查输出字段、ID、覆盖数、标签和固定目录，记录规则版本及哈希。

每批保存有效结果，失败重试可复用断点；最终提交前检查资料是否变化，防止旧输入覆盖新资料。分类结果在事务中保存，可撤销；撤销后新增资料和后续独立改动不应被无差别删除。

整理成功只说明结果符合程序约束。错误的任务、监督方式和先验标签仍可能通过结构校验，重要筛选应核对摘要或原文。

## 重复记录

重复身份由程序核对，不由模型决定。依据包括 DOI、arXiv / 来源标识、相同 PDF，以及能匹配的标题、年份和作者。

冲突或仅同名但身份不明的记录保留。确认重复后默认合并显示，保留各来源和文件，历史引用 ID 不变；不进行物理删除。需要查看所有来源时，可显示被折叠项。

## 报告名称

报告显示名称与文件身份分开，支持手动名称和模型建议的中文名称。自动命名只使用问题、标题及结论片段，最多处理 20 份，不重新分析论文，也不改变正文结论。

## 缺全文

缺全文页默认优先呈现最近研究的相关资料，可切换会话或整个工作区。它核对实际本地文件、隐藏状态和重复项，不把整库所有题录都当作必须补齐的资料。

- 当前分析需要、仅入库及历史相关性备注分别说明。
- 原文入口优先使用保存的 DOI、来源 URL 和公开记录。
- 提供 Scholar、Semantic Scholar、arXiv 题名搜索及有依据的会议数据库入口，不让模型编造下载地址。
- 补充 PDF 后，原报告不会自动改写；在原会话重新分析即可使用新全文。

列表每页最多 100 条。建议先补齐对当前问题关键、尚无可用证据的论文，摘要已足够回答的问题不必为消除计数而上传全部全文。
