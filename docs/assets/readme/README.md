五张页面截图直接以 2880 × 2080 像素捕获，没有放大旧图。过程图由当前事件接口回放人工示例记录，不包含真实模型调用，也不表示性能或结论质量。

## 重新捕获

安装开发依赖并构建任务内核后，还需要 Node.js、Playwright 和 Chrome。在项目根目录运行：

```powershell
.venv/Scripts/python.exe scripts/capture_readme.py
```

Playwright 不在默认模块路径时，使用 `--playwright` 指向已安装的模块；`--node` 可指定 Node.js 程序。工具固定使用 `work/readme-capture` 保存临时文档示例，运行真实本地服务，只连接回环地址，不调用模型或导入私人工作区。完成后删除临时目录，在素材目录保留 `capture.json` 图片与前端文件的校验记录；pytest 的测试目录不受影响。

更新后应逐张检查文字、布局和隐私，再刷新公开源码及软件包。图片说明必须区分界面演示和真实研究结果，不用概念图代替实际功能。

封面和社交预览为项目制作的视觉素材。依赖许可见[第三方说明](../../../THIRD_PARTY.md)，当前使用方式见[首页](../../../README.md)。
