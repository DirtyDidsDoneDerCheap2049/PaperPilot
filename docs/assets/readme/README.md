功能截图拍摄于 2026-09-23。运行项目的实际 FastAPI 应用，通过 Chrome 打开桌面端使用的同一套 HTML、CSS 和 JavaScript，使用 1440 × 900 的视口和 2 倍像素密度截图。图片展示应用内容区，不包含 pywebview 的 Windows 窗口边框。截图没有手绘控件、修改布局、替换文字或插值放大，文件格式为无损 PNG。

截图使用隔离工作区：一个人工编写的示例会话、三条虚构论文题录和一份手写示例报告。它们只展示页面交互与排版，不作为模型输出、论文分析效果或已发表论文的证明。未读取私人会话，未配置密钥，也未为截图发起付费模型请求。截图中的部分名称和报告布局早于后续更新；当前窗口名为 PaperPilot，新报告使用“候选研究空白”章节。

README 中的截图可以点击查看原图。修改截图时应重新从实际应用拍摄；保留足够分辨率，并检查密钥、个人路径、私人论文和通知。分享图允许缩小真实截图以适应封面，但不能用它代替功能原图。
