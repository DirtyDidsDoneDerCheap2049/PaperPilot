# 版本记录

版本说明记录用户可见功能和架构变化，不代替接口文档或逐次测试日志。

## 未发布：v0.2.0-preview.1

- 根据问题选择研究行动，支持指定资料核查、开放调查、数值比较和综述。
- 默认全文处理上限由首发的 50 篇调整为 60 篇，补齐会话附件承接、读取覆盖及时间过滤。
- 论文库自动分类、独立方法筛选、增量整理和重复折叠，支持中文报告显示名称。
- 本地 ONNX embedding、Chroma 与 SQLite FTS 混合检索接入 Agent；按输入容量直读全文或检索章节，不再固定截取字符数。
- 多版本证据缓存和供应商用量统计；独立论文默认并发 3。
- 对话内结构化流式显示，减少重复重绘，直接讨论默认展开，Windows EXE 不附带控制台。
- Naturawrite 报告写作与自动报告修订；内容检查后仍有缺口时交付已核实部分。
- 缺全文来源入口和按范围导出的研究资料包。

完整功能、架构、升级及验证范围见 [v0.2.0-preview.1](releases/v0.2.0-preview.1.md)。版本号为草稿，实际发布以仓库标签和 Releases 为准。

## v0.1.0-preview.1

首个 Windows 预览版提供研究方向检索、多论文解析、证据提取、覆盖分析、候选空白及报告。桌面界面保存会话、论文和研究记录。

首发已经采用 C++17 持久任务内核、Python 分析进程、默认 SQLite、可选 MySQL 和 OpenAI Chat Completions 兼容模型接口。软件包无需安装 Python 或数据库服务，仍需 WebView2 和自备模型 API。

全文获取、结论质量、任务恢复和安装环境有预览版限制。不同版本的实际源码与附件以其标签为准，不用当前功能说明推断旧版能力。
