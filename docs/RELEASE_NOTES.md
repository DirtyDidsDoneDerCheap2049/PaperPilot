# PaperPilot v0.1.0-preview.1

PaperPilot 的首个 Windows 预览版：围绕一个研究方向检索和分析多篇论文，比较方法与原文证据，整理候选研究空白。当前更适合深度学习方向的研究者使用。

## 开始使用

1. 下载 `AIReader-windows-preview.zip`，完整解压 `AIReader` 文件夹。
2. 打开 `AIReader.exe`，在“连接与设置”中填写自己的模型服务地址、API Key 和模型名称。
3. 输入研究问题。已有论文可批量导入 PDF，作为本轮分析的补充资料。

需要 Windows 和 WebView2 Runtime，无需另外安装 Python、MySQL 或部署服务器，也无需注册 PaperPilot 账号。程序文件名沿用 AIReader，窗口内名称为 PaperPilot。

## 本版功能

- 本地论文库、历史会话、全文获取状态、PDF 补充与研究报告。
- 对话内显示研究过程，模型发现逐步呈现；长篇思考不展开，也不进入报告。
- 新报告先列候选研究空白，逐项说明“空白点”和“与已有工作的差异”，证据较弱处标注“待核实”。
- 使用自己的 OpenAI Chat Completions 兼容 API；服务商模型与参数可以配置，并非所有厂商均已验证。
- 本地 SQLite 默认开箱使用，MySQL 为高级可选项；可导出供其他模型复核的研究资料包。

## 数据与费用

工作区保存在本机。模型分析会把相关论文文本和对话发送到你配置的服务，费用由该服务账户承担。可选外部解析和向量服务有各自的数据传输与费用。

本软件包不附带作者的论文、会话、数据库或 API 密钥。

## 已知限制

- 全文下载受访问权限和来源限制，失败时可手动补充 PDF；本地解析不含 OCR。
- 研究结论可能有遗漏或误判，候选空白需结合原文核查。任务成功和模型自动复核不代表新颖性已经得到证明。
- 长论文提取、补查轮次、模型请求数与运行时间有上限；中断后的任务重试不是任意步骤续跑，可能再次计费。
- 当前没有自动更新和跨设备同步。尚未完成干净 Windows 系统安装验证，软件包未做代码签名，因此以预发布版本提供。
