# 工作区与数据

默认桌面版使用 SQLite，无需安装 MySQL。首次打开创建自己的空工作区，模型 API 由用户配置。工作区位置可以在「连接与设置 → 高级选项 · 工作区与数据库」查看。

默认位置：`%LOCALAPPDATA%/AIReader/workspace`。指定其他位置：

```powershell
./AIReader.exe --workspace D:/ReaderData/research
```

同一个工作区同时只能由一个 Reader 实例打开。数据库保存会话、论文记录和证据，PDF、报告和索引也在工作区内。程序升级时替换程序目录，保留工作区。

## 导入已有记录

工作区导入会保留历史研究资料。继续原会话使用「研究 Agent」，会承接上一轮论文集合；补全文后也应使用这个模式重新分析。「讨论结果」只讨论已有内容，不执行检索和研究流程。全文处理篇数在连接设置里查看和调整，旧工作区可能仍保留此前的 10 篇配置。

一个研究会话围绕具体实现方向展开。例如补全文后可以问：“核查新全文是否已经覆盖上一轮候选的差异”，从报告想到新机制时可以问：“查这个机制的来源方向，以及迁移到当前任务的已有工作”。上一轮方向和候选状态会作为上下文传入；旧报告不会被改写，新一轮可能推翻旧判断。当前不会在报告生成后自行持续检索，需要你提交下一轮研究请求。

先关闭旧工作区对应的程序，目标应是一个尚不存在的目录：

```powershell
./AIReader.exe --workspace D:/ReaderData/new --import-history D:/ReaderData/old
```

此入口只支持 SQLite。原工作区只读，文件复制并校验，数据库内结构化文件路径会重定位；历史报告正文不改写，其中的旧绝对链接可能需要原路径。密钥、旧向量缓存和旧任务队列不导入。重新打开同源成功副本时复用记录，不覆盖后续对话；其他已有目标拒绝覆盖。

## 备份与恢复

关闭 Reader 后，复制完整工作区到另一块磁盘。恢复时用 `--workspace` 指向副本，核对会话、PDF 和报告都可打开。不要在运行中只复制 `.db` 文件，也不要让多台机器同时使用网络盘里的同一数据库。

Windows 密钥使用当前系统用户的 DPAPI 加密，换电脑或账号后应重新配置。加密凭据仍属于私人文件，不应公开。MySQL 工作区还需要数据库快照，见 [MySQL 说明](MYSQL.md)。

## 分享与开源

工作区、备份、日志和研究报告不属于公开源码。分享单份报告前检查研究问题、文件路径、未发表内容与论文使用权限。不要把整个工作区作为示例数据上传。
