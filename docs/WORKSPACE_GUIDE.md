# 工作区与备份

工作区保存论文、解析、证据、会话、报告和配置。程序升级与资料存储分开：替换程序文件，不自动导入旧记录，也不重新生成历史报告。

## 选择工作区

公开桌面包默认使用 `%LOCALAPPDATA%/AIReader/workspace`。实际位置可在「连接与设置 → 高级选项 · 工作区与数据库」查看，也可启动时指定：

```powershell
./AIReader.exe --workspace D:/ReaderData/research
```

维护用本机入口为 `dist/PaperPilot.exe`，更新工具沿用 `work/preview/workspace`。这是开发目录约定，不是公开包的默认数据位置。程序文件名 AIReader 与数据目录名为兼容旧版本保留。

一个工作区同时只允许一个应用实例。SQLite 为默认存储；选择 MySQL 需独立数据库，切换后端不会自动迁移资料。

## 备份与恢复

先通过界面停止任务并关闭程序，再复制完整工作区。不要只复制数据库文件，PDF、解析和报告路径也属于记录。

源码环境可以使用备份工具，目标目录应不存在：

```powershell
.venv/Scripts/python.exe scripts/backup_workspace.py D:/ReaderData/research D:/ReaderBackup/research-copy
```

恢复时把副本放到独立位置，启动参数指向它，核对会话、全文、报告和引用后再使用。MySQL 还需同时恢复对应数据库快照，见[MySQL 备份](MYSQL.md)。

本地索引是派生数据，可重建；复制它能减少恢复后的重建时间。Windows 密钥使用原账号的 DPAPI 加密，换电脑或系统账号后通常需要重新配置。

## 导入历史 SQLite 记录

首次导入使用新目标：

```powershell
./AIReader.exe --workspace D:/ReaderData/imported --import-history D:/OldReader/research
```

工具只读复制和校验源资料，并重定位结构化文件引用。已有目标不能被不同来源覆盖，同源已导入副本再次打开时复用，不重放旧记录。

导入论文、会话、消息、证据和报告，不复制 API 密钥，不激活旧任务队列，也不迁入旧向量缓存。报告正文不改写，其中手写的绝对链接可能仍指向旧位置，应人工检查。

关闭源工作区程序后再导入。后续删除状态以目标副本为准，升级不会从旧目录重新恢复已删除会话。

## 升级与中断

先备份工作区，再完整替换程序文件，保留实际工作区选择。不要把运行过、包含私人数据的目录当成公开安装包。

重启后活动任务标记为中断，不自动重复付费；排队任务可继续。手动重试从流程起点开始，可能复用有效证据，也可能重新调用模型。先检查已有报告和消息。

数据库、任务状态和文件没有共同事务；文件改名、删除和旧库升级也没有完整回滚框架。重要升级在副本验证，回退使用同一版本的程序和完整数据备份。

分享资料包、日志或工作区前检查研究内容与私人路径。加密 API 密钥不能保护未加密的论文和会话正文。
