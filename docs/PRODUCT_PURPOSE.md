# 产品目标

PaperPilot 是用于研究方向分析的桌面论文 Agent。它围绕问题检索、阅读和比较多篇论文，把已有工作、原文依据及尚未解决的问题整理成报告。单篇解析是其中一个工具，多篇论文也只是资料规模；最终交付的是对研究问题的回答。

当前更适合深度学习方向的研究者使用。这与已有工具和使用样例有关，流程不限定计算机领域，也不为某个研究方向安装专用插件。

## 使用场景

| 问题 | 交付内容 |
| --- | --- |
| 某项方法或组合是否已有工作，差异在哪里 | 已有工作、候选空白、最近工作差异、证据及验证思路 |
| 一段时间内某指标的最佳报告值是多少 | 核实数值、模型归属、时间范围、比较表和评测条件 |
| 一组论文有哪些路线和共同问题 | 主题组织、方法比较、证据和研究限制 |
| 指定论文是否支持某个说法 | 原文核查、引用和明确的支持或不支持结论 |
| 已有报告需要改写或调整结构 | 基于保存资料的新修订版，保留原稿 |

## 核心使用过程

1. 输入研究问题，可补充条件、选择库中论文或导入 PDF。
2. Agent 确定目标、资料范围和完成条件，在预算内选择检索、来源核对、全文检索、阅读和分析。
3. 对话实时显示逐篇发现与报告草稿；任务结束后交付完整或部分报告。
4. 在原会话补充资料、核查结论或修改报告。论文、引用和报告版本继续保存在工作区。

流程可以返回检索和阅读，也可以在指定资料已经核查后直接结束。它不要求每个问题都经过创新画像、空白生成和候选评审。具体调度见[研究行动](ADAPTIVE_RESEARCH.md)。

## 结果要求

报告先回答所问问题，再提供依据和边界。数值归属于实际模型、数据集及指标；候选空白说明与已有工作的差异；原文、摘要和模型推断分别表达。无法获得全文、日期不明或尚未读完的资料，不能悄悄计为已核实。

系统运行成功与研究结论正确是两件事。任务记录和结构检查保证不了检索完整性、语义理解或研究新颖性，结论仍应接受原文核查及实验验证。

## 故障与降级

- 全文不可得：给出原文和搜索入口，允许补充 PDF，或基于摘要交付受限结论。
- 证据不足、预算耗尽或内容检查仍未通过：交付可核实的部分，列明缺口，保存检查记录。
- 鉴权、余额、外部服务故障或取消：按实际任务状态反馈，不伪装成研究成功。
- 应用关闭或崩溃：保存已有资料，活动任务在重启时标记中断；手动重试可能再次计费。

## 产品边界

默认本地使用、自备兼容模型 API，无需注册账号或部署数据库。MySQL 和外部解析为可选项。当前不提供多用户协作、自动跨设备同步、无人值守云任务、自动更新或“保证创新”的服务。

实现和可靠性限制见[架构](ARCHITECTURE.md)，使用及备份见[工作区指南](WORKSPACE_GUIDE.md)。
