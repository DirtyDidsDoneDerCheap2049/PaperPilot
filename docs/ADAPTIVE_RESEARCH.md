# 研究调度

研究流程由问题和现有证据驱动。Agent 先生成计划，再选择工具行动；可以分析后补查，也可以核对完指定资料后直接交付，不要求所有问题都进入研究空白分析。

## 计划与工具

任务类型包括研究空白、数值比较、综述、事实核查及其他问答。计划记录目标、所需信息、成功条件、资料范围、时间窗、比较分组和报告章节。

| 行动 | 内容 |
| --- | --- |
| `search` | 检索可回答问题的论文，应用时间条件 |
| `lookup` | 核对已有论文的公开日期、来源及全文入口 |
| `retrieve` | 在已有全文中混合检索章节、表格和出处 |
| `read` | 获取或读取指定论文，提取问题所需证据 |
| `analyze` | 综合已读资料，比较数值或核查研究候选 |
| `deliver` | 根据已分析证据交付答案，或说明实际阻断 |

这是一个规划模型调用工具，没有并行子代理。独立论文操作可并行，决策和综合分析按依赖执行。

## 资料范围

- `provided`：核对本次指定或会话中引用的已有资料，不搜索新论文，也不自动扩展到其他模型。
- `open_literature`：允许公开检索、补查和补读，仍受时间窗及预算约束。

模型判断追问是否承接原问题，但程序只允许引用已知论文 ID。标题和历史助手回答提供线索，不能代替已读原文。已读或选定资料不会被新的低相关搜索结果替换。

指定论文、已纳入且本地有全文的论文、需要追查的更优基线属于交付前优先补读项。提前交付时，程序在预算内补读并预留分析。未读、失败和无法获取全文的资料单独列出，不用“阶段完成”暗示全部覆盖。

## 预算与停止条件

缺省最多 16 次行动判断、12 条新查询；新工作区论文处理上限为 60，可设为 0–100。模型请求数和时限另行限制，默认 200 次、120 分钟。上限是预算，不要求每轮处理满额。

重复查询不再执行，同篇读取最多尝试两次，没有新增证据的重复分析受限制。证据未分析不能直接作为结论交付，最后一个行动步骤留给分析或交付。

无效字段、空值、错误类型或行动会被检查。无法执行的规划按已有资料降级为读取、分析或交付，不凭空补检索式，也不增加格式修复请求。诊断保留在 `planner_output_errors`。

## 日期与搜索

相对时间按当前 Asia/Shanghai 日期计算，不采用模型知识截止日期。“最近一年”为向前一年，“一两年”按两年处理并说明解释。

Semantic Scholar、arXiv 和 Crossref 接收日期约束，合并结果再检查日期与相关性，先排序再截断。明确范围外论文排除；只有年份或月份且跨边界时，保留为日期待核实，不能计入近期确认排名。

优先采用首次公开时间，较晚的期刊发表不把旧预印本变成新论文。有效 arXiv 编号只能恢复其包含的月份，不能推算具体日。规则见 [arXiv 标识说明](https://info.arxiv.org/help/arxiv_identifier.html)。

用户明确要求某分组比较全部年份时，计划通过 `comparison.all_time_groups` 保留该范围；其他分组继续执行原时间窗。日期和来源持久化到论文记录。旧库增量添加可空字段，MySQL 升级需在独立实例验证。

正常零结果与来源失败分别记录，429 有限重试。备用来源也执行时间检查，有限搜索不能证明已穷尽文献。

## 会话与附件

同会话从讨论切回研究时，带入最近消息、上一轮计划及仍保留的上传或选定论文。短回复可由模型结合前文理解，不依靠“继续”“之前”等关键词。独立新问题不自动承接旧任务。

最近消息最多 16 条、16,000 字符，优先保留最新修改，长消息保留首尾。附件引用单独恢复，最多 100 个 ID，不受消息文本截断影响；不跨会话恢复已删除附件。失败的空报告不会遮住之前有资料的研究结果。

首次执行保存上下文快照，原任务重试沿用它；新任务读取当前历史及删除状态。用户消息保存原始输入，不用内部扩展提示词替代。

讨论模式最多使用 8 篇论文，每篇 10,000 字符、合计 36,000 字符。本地 PDF 从全部页面按问题选择摘录；摘录未出现某项结果，不意味着原论文没有报告。

## 数值与比较

数值证据包括模型变体、数据集、指标、原表数值、训练条件及所需速度和硬件信息。教师、对照基线和消融行单独标识，不把引用成绩算给论文提出的方法。

表格绑定支持纵向行、横向模型表头，以及数量一致的模型列与数值列。Ours 只用于能对应本论文提出模型的行；页码、表头及表注保留供核查。扫描件和复杂表格仍可能解析失败。

默认 `reported_results` 比较同一目标数据集和指标的文献报告值：先给核实结果，再说明训练数据、分辨率、迭代和硬件差异。没有提供 Dmax 或硬件，不会自动否决已有 EPE；不同数据集、指标或教师成绩则不能移用。

只有明确要求统一条件或受控复现时，才采用 `controlled_comparison`。论文报告值排序不证明控制变量后的方法优劣。更优对照行先追查原论文，未核实时作为线索，不计确认值。

单篇缺少的辅助信息与整轮未完成项分开保存。未提取到数值不能写成“论文没有报告”；正文和表格不一致时说明来源差异。

## 报告与恢复

报告按任务类型组织：空白点、数值答案、综述结论或事实核查结果在前，证据和范围在后。初稿检查后允许一次修订；仍不合格时，交付由已核实证据整理的部分报告，不把检查意见或思考过程当作最终答案。

桌面普通重试从任务起点运行，可能复用已有证据；不支持任意行动自动恢复。维护验证工具可在隔离工作区使用保存检查点，保留查询、读取尝试及累计请求预算。

| 入口 | 用途 |
| --- | --- |
| [test_adaptive_research.py](../tests/test_adaptive_research.py) | 日期、来源过滤、数值归属及非线性流程回归 |
| [inspect_research_run.py](../scripts/inspect_research_run.py) | 只读查看研究快照与资料范围 |
| [validate_adaptive_research.py](../scripts/validate_adaptive_research.py) | 默认检查配置，`--execute` 才调用模型；检查点必须属于隔离目录 |

合成样例验证程序行为，不代表研究准确率。在线验收需人工核对原论文日期、模型和数值行、引用、资料覆盖以及来源失败。
