# 模型用量与缓存

研究成本由输入、输出、模型参数、供应商定价和重复调用共同决定。本地缓存与供应商输入缓存用途不同，不能合并为一个“缓存命中率”。

## 三种复用

| 机制 | 复用内容 | 是否请求模型 |
| --- | --- | --- |
| 本地证据缓存 | 同一原文、问题和配置下已经核实的提取结果 | 有效命中时跳过该次提取 |
| 供应商前缀缓存 | 服务端可复用的相同输入前缀 | 仍请求模型，费用按供应商规则 |
| 本地全文索引 | 相同原文和 embedding 模型生成的块及向量 | 本地索引不调用研究模型 |

编程对话经常追加同一长前缀，论文任务则可能切换原文、问题、证据包和报告结构，供应商命中率不能直接与编程场景对比。稳定规则和正文放在变化要求之前有利于前缀复用，但不能保证固定比例。

## 本地证据缓存

[证据缓存](../src/analysis/evidence_cache.py)按实际提示词、来源哈希、问题要求、服务地址、模型和有效参数区分版本，保存在工作区 `.agent_history/cache/question_evidence`。

同一论文切换问题后再返回，仍可命中之前版本。来源、规则或配置变化时重新提取，复用前检查引用是否仍匹配原文。失败结果不覆盖有效画像，仅改报告结构不应导致重读论文。

论文库整理另有输入指纹缓存，新增或变更项才重新分类。索引复用按原文及模型指纹判断，不把未完成索引计为可检索。

## 任务用量

任务记录显示服务返回的输入、输出、输入缓存命中与本地复用篇次，并显示获得用量的请求覆盖数。

- DeepSeek 的 `prompt_cache_hit_tokens`、`prompt_cache_miss_tokens` 用于输入缓存统计。
- OpenAI 兼容服务的 `cached_tokens` 存在时用于统计；不提供时保留未知。
- 输入缓存比例 = 命中输入 token ÷（命中输入 token + 未命中输入 token）。
- 输出通常已包含 reasoning token，不再次相加。
- 失败或取消响应已经返回用量时也计入；没有返回用量不记成免费。

这些是所配置服务的回执，不是账户账单。若一个 API Key 同时被其他工具使用，供应商控制台的总量不能直接归属于 PaperPilot。

## 预算

新工作区默认限制 60 篇全文、200 次模型请求及 120 分钟。全文范围可设为 0–100，单次输出、超时、并发和上下文容量可调整。SDK 重试关闭，应用有限重试占用请求预算。

请求数和时间没有统一换算成金额，也不覆盖外部解析收费。供应商额度、余额和价格应另行管理。取消可停止本地后续工作，无法保证已发送请求不再计费。

## 缓存评估

使用同一资料、问题、模型和参数，先测冷运行，再测相同问题复用、切换问题后返回、原文变化及仅改报告。分别记录：

1. 实际请求数和有用量回执的覆盖数。
2. 本地复用篇次、供应商输入缓存比例及输出量。
3. 完成率、结论与原文是否一致。
4. 供应商账单和总耗时。

本地模拟测试能验证计数、缓存失效和跳过请求，不能证明在线缓存比例或费用下降。没有同条件在线测量，不给出成本节省百分比。
