# 主张、证据与覆盖

各研究方向使用同一套主张与证据流程。方法组件沿用论文自身名称，不预设立体匹配阶段或固定书目。蒸馏等方法的证据规则按语义使用，不按领域切换分析分支。

## 证据记录

直接全文证据需要能匹配解析文本，记录来源 ID、文件路径、SHA-256 和字符范围。摘要、全文、推断及解析失败分别标记；先验笔记不计为论文全文证据。

结构检查确认字段和引用可定位，不能证明语义蕴含。支持关系不能补出原文没有的教师、目标、损失或迁移方向。缓存复用前重新检查引文，来源变化后失效。

## 方法事实

- `method_component` 使用论文实际组件名称。
- 迁移关系保存 `source_task` 和 `target_task`，各字段分别绑定证据。
- 方法融合、预训练权重、冻结编码器和注意力结构不自动等于知识蒸馏。
- 蒸馏需要教师、学生、知识传递对象及学习目标的原文依据。否定表达不计为正向证据。
- “未找到”描述本次资料覆盖，不能直接推导某方法不存在。

历史字段 `stereo_matching_stage` 仅作为 `method_component` 的读取别名，新结果不再写入，也不触发专用流程。旧的 `off_topic` 或画像相关性标记不会全局排除论文，新问题重新判断其相关性。

## 研究空白

[方向覆盖](../src/analysis/direction_coverage.py)把当前主张与已验证原文组织为覆盖索引。候选应说明：

1. 尚未覆盖的具体差异。
2. 与最近工作的区别及来源。
3. 支持、反证和资料限制。
4. 可用于区分候选与已有工作的验证思路。

Critic 检查候选的证据、范围和夸大结论。尚未核实的模型改写保留为草案，不因措辞流畅自动升格。候选状态、逐项审查和统计需要一致，但模型复核仍可能漏判。

## 其他任务

数值比较、综述和事实核查采用当前问题需要的证据，不强制生成研究空白。数值归属和评测差异见[研究调度](ADAPTIVE_RESEARCH.md)，最终正文格式见[报告写作](MODEL_OUTPUT.md)。

所有流程保留原文核查要求。来源可追溯、任务完成和字段合法，都不等同于结论正确。
