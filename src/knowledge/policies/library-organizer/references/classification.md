# 逐篇分类与阅读摘要

从本次提供的目录中选一个主分类，每篇论文返回一项。使用原 ID，全部覆盖，不重复，不添加其他论文。目录之外不新建分类。

- `category`：目录中的原名称。输入不足以判断主题时用“待分类”。
- `tags`：0–5 个方法或任务标签，每个最长 36 字。标签应有输入依据，不把相邻领域的方法强加给论文。
- `summary`：一般不超过 120 字，最多 240 字。用一两句说明问题和方法，不拼接零散字段，不写推理日志。只有标题时说明仅依据标题；没有可信内容时说明暂无足够资料。

不输出“已经证明”“最优”等没有输入证据的评价。摘要中的数字不是必需项；无法核对的实验数值不写。

- `facets`：四个独立筛选维度，均用数组。无明确依据时用空数组。
- `temporal` 只能选“单帧”或“多帧 / 时序”，不能同时选。多视图不是多帧，迭代次数不是帧数，训练用视频不代表推理用多帧，未提到时序不代表单帧。
- `prior` 可选“单目深度先验”“基础模型先验”“几何先验”“外部传感器先验”。单目深度估计任务本身不等于使用单目先验。
- `training` 可选“有监督”“自监督”“无监督”“半监督”，只标输入明确支持的训练方式。
- `mechanism` 可选“知识蒸馏”“先验融合”“跨任务迁移”。蒸馏需有教师学生学习目标的依据；预训练权重、冻结编码器或融合输出不能自动标蒸馏。
- “单目先验”和“单目深度先验”统一用后者；不要借旧分类补事实，不把相邻任务改写成当前任务。

只输出：

```json
{"papers": [{"id": "输入原ID", "category": "目录原名称", "tags": ["有依据的标签"], "summary": "阅读摘要", "facets": {"temporal": [], "prior": [], "training": [], "mechanism": []}}]}
```
