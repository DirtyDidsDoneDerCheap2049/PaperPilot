补充论文全文

优先补充与你的研究有关、且没有可用本地全文的论文。不必补齐整个论文库；检索入库不等于必读。先打开原文页或按题名检索，取得 PDF 后上传。仅有摘要也可继续研究，但结论会保留证据限制；上传不会改写旧报告。

怎样查找全文

先用 DOI / 出版社原文页查找 PDF；如需机构权限，可通过学校图书馆的数据库入口登录。再查 Google Scholar 的 PDF / 全部版本、arXiv、作者主页或会议公开库。链接只是查找入口，已记录的 PDF 地址也可能需要访问权限。
